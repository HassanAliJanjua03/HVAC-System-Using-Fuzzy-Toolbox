# HVAC Control Using Fuzzy Logic

**Intelligent Control · HVAC · MATLAB**

An academic study of fuzzy logic applied to heating, ventilation and air conditioning control.

## Engineering highlights

- Fuzzy inference as an approach to rule-based control.
- HVAC application context linking automation and intelligent decision-making.
- Original engineering report available for review.
